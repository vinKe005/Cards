# Sorteio de Desafios

Sorteador de cartas de desafios para grupos, com tema do Egito antigo.

Site: https://vinke005.github.io/cards/

O site é protegido por senha. Todo o conteúdo (página, cartas e imagens) fica criptografado em `dados.enc` (AES-256-GCM, chave derivada da senha com PBKDF2-SHA256) e só é aberto no navegador depois que a senha certa é digitada.
